Privacy Policy

Last updated: November 17, 2026

Workspace Automation is a personal tool used only by its owner. It accesses the owner's own Google Drive, Docs, Sheets, Slides and Calendar data, only to carry out actions the owner requests.

  • Data collected: none. The app has no server and stores no data outside the owner's computer.
  • Sign-in tokens are stored only on the owner's computer and are never shared.
  • Sharing: no Google user data is sold, shared with third parties, or used for advertising.
  • Revoking access: access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
